# EHOT Launcher — релизы

Здесь лежат только **установщики** (артефакты CI): `.exe` для Windows и `.dmg` для macOS.
Исходный код лаунчера — в закрытом репозитории `Timofei2506/EHOT-Launcher`.

## Зачем отдельный репозиторий

1. Лаунчеру и сайту нужно читать список версий и файлов **без токена** —
   для этого нужен публичный репозиторий, в котором нет исходного кода.
2. Автообновление лаунчера (`GitHubUpdateService`) обращается к GitHub Releases API;
   теперь это API этого репозитория.

## Скачать

* Сайт: https://ehot-launcher-site.vercel.app
* Страница релизов: https://github.com/Timofei2506/EHOT-Launcher-Releases/releases

Каждая версия — git-тег + GitHub Release с тремя файлами и контрольными суммами
(`SHA256SUMS.txt`). Версия `0.1.0` — первая сборка (beta).
